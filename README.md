# Ticketeer

Ticketeer — веб-приложение для обучения и проверки знаний билетных кассиров железнодорожных перевозчиков.

## Возможности

По требованиям система должна поддерживать обучение по тематическим вопросам и билетам, проведение экзаменов, сохранение результатов, просмотр личной и групповой статистики, а также администрирование пользователей, групп и учебных материалов.

Подробные согласованные требования, перечень пока не реализованных возможностей и открытые вопросы приведены в [docs/requirements.md](docs/requirements.md).

## Текущее состояние

Проект находится на начальной стадии разработки.

- Frontend представлен базовым каркасом Vue-приложения: подключены Vue Router и Pinia, но прикладные страницы и маршруты ещё не реализованы.
- Backend-проект и зависимости для REST API, Entity Framework Core, PostgreSQL, JWT и хеширования паролей подготовлены частично; прикладной API и доменная модель ещё не реализованы.
- В корневом `compose.yaml` описан локальный экземпляр PostgreSQL.
- Функциональность авторизации, билетов, экзаменов, профиля, статистики и административной панели является запланированной, а не реализованной.
- UnoCSS входит в согласованный технологический стек, но пока не подключён к frontend.

## Технологический стек

Frontend:

- Vue 3;
- TypeScript;
- Vite;
- Vue Router;
- Pinia;
- UnoCSS (запланирован, пока не подключён).

Backend:

- C#;
- ASP.NET Core;
- .NET 10;
- REST API;
- Entity Framework Core и Npgsql (зависимости добавлены, интеграция не завершена).

- PostgreSQL.

## Требования к окружению

- .NET SDK 10;
- Node.js `^22.18.0` или `>=24.12.0` (согласно `frontend/package.json`);
- npm, поставляемый с установленной версией Node.js;
- PostgreSQL либо Docker с поддержкой Docker Compose.

## Локальный запуск

### База данных

Для запуска PostgreSQL через Docker Compose из корня репозитория:

```sh
docker compose up -d db
```

По умолчанию база данных доступна на `localhost:5432`. Параметры локального подключения указаны в `backend/appsettings.json` и `compose.yaml`.

### Backend

Из корня репозитория:

```sh
dotnet restore backend/backend.csproj
dotnet run --project backend/backend.csproj
```

Профили разработки настроены на `http://localhost:5046` и `https://localhost:7277`. В текущем состоянии точка входа backend не содержит запуска приложения, поэтому работающий REST API пока отсутствует.

### Frontend

```sh
cd frontend
npm install
npm run dev
```

Команда запускает Vite-сервер разработки. Адрес будет выведен в терминале.

Дополнительные проверки frontend:

```sh
npm run type-check
npm run lint
npm run build
```

Перед запуском необходимо установить зависимости. В рамках первоначальной подготовки репозитория зависимости не устанавливались.
